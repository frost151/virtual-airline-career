# Virtual Airline Career

Соло-карьера виртуальной авиакомпании для MSFS 2024.

## Запуск

```
npm install
npm run dev      # режим разработки с горячей перезагрузкой
npm run build    # сборка
npm start        # запуск собранной версии
npm run dist:win # exe: установщик и портативная версия в dist/
```

npm 11 блокирует установочные скрипты пакетов: для `electron` и `esbuild` они уже разрешены в `package.json` (`allowScripts`).

Тесты: `npx vitest run` (трекер прогоняется на синтетическом демо-полёте).

## Трекер полётов

- Подключение к MSFS 2024 через SimConnect (`node-simconnect`), автоматическое переподключение каждые 5 с.
- Без симулятора — «Демо-полёт» Пулково → Шереметьево в 30 раз быстрее реального времени.
- Профили аддонов — `data/aircraft-profiles.json`. Пока профиль не проверен (`verified: false`), правила по свету для него не применяются; сырые значения переменных видны в «Диагностике переменных» на экране полёта.
- Телеметрия каждого полёта пишется в `%APPDATA%\Virtual Airline Career\recordings\*.jsonl` — для разбора спорных случаев.

## Данные мира (`data/`)

- `airports.json` — аэропорты из OurAirports, пересобрать: `npm run data:airports`
- `aircraft-types.json` — каталог типов самолётов
- `airlines/*.json` — реальные авиакомпании по регионам (срез на старт мира), можно править вручную

После правок запускайте `npm run data:validate`: проверяет коды аэропортов и типов, дальность маршрутов и длину ВПП.

Сохранения (профили) лежат в `%APPDATA%\Virtual Airline Career\profiles\*.sqlite`.
База данных — встроенный в Electron `node:sqlite`, нативные модули и Visual Studio не нужны.
